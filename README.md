# ⚽ FPL Squad Manager & Game

A Python-based Fantasy Premier League (FPL) squad management and selection application.

## 🚀 Features
* **Player Data Integration:** Reads player stats and performance metrics from `players.csv`.
* **Smart Captain Selection:** Algorithm to calculate optimal captain choice based on expected goals (xG) and fixture difficulty.
* **Squad Validation:** Filters and organizes players by position and price.

## 🛠️ Project Structure
* `fpl.py`: Main application code containing logic and UI/CLI interactions.
* `players.csv`: Dataset containing player information, prices, and stats.
* `.gitignore`: Excludes unnecessary local files and SQLite database files.
